# Research Desk design

The user delegated the design choice. A quiet editorial research index: warm paper, deep green navigation, rust selection, ruled lists, and a generous document reader. Grounded directions considered: library catalog, lab notebook, paper-review table, reference manager, meeting agenda, source browser, and academic journal index. The concept seed assigned index 7, the academic journal index; the app follows that direction.

The library list is the navigation spine; the reader is the working space. Topic labels remain plain language. Document title, research date, type, source page, and source attribution establish hierarchy. Avoid decorative technical imagery and dashboard statistics. The first viewport includes real source material, not a blank shell.

Colors: paper #f6f4ed; ink #232c29; green #203d35; rust #a3432c; muted ink #64716b; divider #dedfd6. Fonts: self-hosted Source Sans 3 and Lora. Body text 16px; reader text 17px; compact navigation 14px. Underlines and focus use rust. Desktop has sidebar, list, and reader; narrow screens navigate list-to-reader, with a Back button. Motion is a brief reader reveal, removed for reduced-motion users.

Source statements are labeled as source notes, not verified facts. Dates are authored dates only. Original PDF links and page-level extracts remain adjacent. New notes save explicitly, with visible persistence state. Import and export are ordinary inline workflows.
